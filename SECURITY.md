# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's private vulnerability
reporting on this repository (the **Security** tab, then **Report a vulnerability**). We read every report, confirm it,
and reply in that thread.

Include what you found, the version or commit, the steps to reproduce it, and what an attacker could do with it. Do not
test against servers you do not run.

## Supported versions

Patchvia DNS has not had a stable release yet. Security fixes go to the latest release on `main`.

## What we consider in scope

The DNS server and API, the web console, the official container images and the deployment files in `deploy/`.
